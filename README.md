How to run the application:

1. Make sure you have created a .env file and inserted your own values. A template for this file can be found in env.template.

2. Use the command: docker-compose up --build

Postman test data can be found here: [https://www.postman.com/workspace/My-Workspace~2f42e812-1503-458c-8ebc-3951761babbe/collection/41326023-96ccd85e-1da2-41b9-82c4-2a04c986262a?action=share&creator=41326023](https://.postman.co/workspace/My-Workspace~2f42e812-1503-458c-8ebc-3951761babbe/collection/41326023-96ccd85e-1da2-41b9-82c4-2a04c986262a?action=share&creator=41326023)

By default, if you do not change the port in the Docker environment template, it will be set to 8088. If you decide to change it, don’t forget to update the Postman request URLs accordingly.
